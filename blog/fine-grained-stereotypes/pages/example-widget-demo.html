Interactive widget patterns

This page is not part of the paper narrative — it's a working reference for the two interactive-figure patterns you described: a draggable node-link network, and a Plotly figure driven by buttons. Copy the markup/JS from here into real sections once you have data to plug in, then delete this page.

On this page

Draggable network

A minimal D3 force-directed graph. Nodes are draggable; the simulation re-settles as you move them. This is the pattern to extend for, e.g., a circuit diagram where nodes are attention heads / MLP layers and edges are attribution weights.

Button-driven Plotly figure

A Plotly figure whose data updates via Plotly.react when a button is clicked, rather than a full redraw. Swap the two placeholder datasets below for, e.g., stereotype-score distributions per demographic axis.

Sizing note

Both widgets above use class="widget full-bleed", which extends the figure into the sidenote margin for extra width — appropriate for data-dense figures. Drop full-bleed to keep a figure within the normal text column instead.
